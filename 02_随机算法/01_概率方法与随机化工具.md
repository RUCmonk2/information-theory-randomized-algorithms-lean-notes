# 概率方法与随机化工具

## 1. 第一组工具

### Union bound

```latex
\Pr\left[\bigcup_i E_i\right] \leq \sum_i \Pr[E_i].
```

用途：把多个局部失败事件合并成整体失败上界。注意它不要求事件独立，通常会比较松。

### Linearity of expectation

```latex
\mathbb{E}\left[\sum_i X_i\right] = \sum_i \mathbb{E}[X_i].
```

用途：分析随机计数、碰撞数和随机图中的边数；不要求 `X_i` 独立。

### Markov 与 Chebyshev

```latex
\Pr[X \geq a] \leq \frac{\mathbb{E}[X]}{a},
\qquad
\Pr[|X-\mu|\geq t] \leq \frac{\operatorname{Var}(X)}{t^2}.
```

用途：先建立粗略尾界，再判断是否需要更强的集中不等式。

### Chernoff/Hoeffding

对独立有界随机变量给出指数级尾界。先掌握二项分布版本，再学习 moment generating function 的证明。

## 2. 随机化范式

- Monte Carlo：运行时间通常受控，但答案有小概率错误；
- Las Vegas：答案总是正确，但运行时间是随机变量；
- amplification：独立重复并取 majority/minimum/median，降低失败概率；
- randomized rounding：先求连续解，再随机化为离散解并分析期望和偏差；
- random hashing：用碰撞概率换空间或时间。

## 3. 练习

1. 用 indicator variable 计算 `n` 个球随机落入 `n` 个桶时的期望空桶数。
2. 用 Chebyshev 和 Chernoff 分别估计 Bernoulli 样本均值偏离 `epsilon` 的概率，比较界的数量级。
3. 写一个重复运行的 Monte Carlo primality toy tester，记录错误概率如何随重复次数变化；不要把它当作生产密码学实现。
4. 对 reservoir sampling 证明每个流元素最终被选中的概率相同。

## 4. 证明书写模板

```text
定义随机变量/事件
-> 写出期望或矩母函数
-> 指明独立性/有界性假设
-> 套用不等式
-> 解出参数与失败概率的关系
-> 报告时间、空间和放大策略
```

## 完成标准

每个不等式都能写出适用条件；不能只背“Chernoff 很强”，却说不清哪些变量必须独立、边界如何依赖 `epsilon` 和 `delta`。
