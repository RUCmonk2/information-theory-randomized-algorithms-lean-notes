## 学习目标

信息论部分重点不是背公式，而是掌握三个视角：

1. 不确定性如何被量化；
2. 共享信息如何被分解和估计；
3. 压缩、通信和学习问题如何转化为可证明的下界。

## 学习顺序

1. 讲义第 1 章：概率、自信息、熵和二元熵；
2. 讲义第 2 章：联合/条件熵、KL、互信息和数据处理；
3. 讲义第 3 章：前缀码、Kraft、Huffman、AEP 和信源编码定理；
4. 讲义第 4--5 章：DMC、BSC/BEC、容量、随机编码与 Fano 逆定理；
5. 讲义第 6 章：Sketch、通信复杂度、side information 和 verifier feedback；
6. 讲义第 7 章：综合习题与参考答案。

## 每一章必须留下什么

- 一张公式卡：定义、单位、边界情况、一个数值例子；
- 一张关系图：哪些量由联合分布决定，哪些量需要条件分布；
- 一个“证明骨架”：只写关键不等式和每一步使用的假设；
- 一个与图流/Sketch 或 AI4Math/AI4TCS 的连接点。

## 常见误区

- 熵不是“语义信息量”的唯一度量，它依赖随机变量及其分布；
- KL 散度不是距离，一般不对称，也不满足三角不等式；
- 互信息为零表示统计独立（在离散/连续适当条件下），但不代表因果无关；
- 经验交叉熵下降不自动等价于获得了有用的算法或证明；
- 不能把一个有限 benchmark 的压缩率或误差直接推广成一般性下界。
