## 2. 信息量与熵

对离散事件，self-information 定义为：

```latex
I(x) = -\log p(x).
```

随机变量 `X` 的熵为：

```latex
H(X) = -\sum_x p(x)\log p(x) = \mathbb{E}[-\log p(X)].
```

先固定使用以 2 为底的对数（单位 bit），再切换自然对数（单位 nat），避免单位混乱。

必须会解释：均匀分布在支持集固定时熵最大；确定性变量熵为 0；熵是分布的函数，不是单个观测值的标签。

## 3. 条件熵、互信息和 KL

```latex
H(X|Y) = -\sum_{x,y} p(x,y)\log p(x|y),
```

```latex
I(X;Y) = H(X)-H(X|Y) = H(Y)-H(Y|X),
```

```latex
D_{KL}(P\|Q) = \sum_x P(x)\log\frac{P(x)}{Q(x)}.
```

要能从定义推出：

- `H(X,Y) = H(X) + H(Y|X)`；
- `I(X;Y) = D_KL(P_{XY} || P_X P_Y)`；
- `D_KL(P||Q) >= 0`，等号当且仅当分布相同（在适当绝对连续条件下）；
- `I(X;Y) >= 0`，并用它判断独立性。

## 4. 手算任务

1. 设 `X ~ Bernoulli(p)`，画出 `H(X)` 随 `p` 变化的曲线，并解释 `p=1/2` 为什么达到最大值。
2. 构造两个相关但不完全决定彼此的二元变量，计算 `H(X)`, `H(Y)`, `H(X|Y)`, `I(X;Y)`。
3. 取 `P=(1/2,1/2)`, `Q=(3/4,1/4)`，计算 `D_KL(P||Q)` 和 `D_KL(Q||P)`，确认它们不相等。
4. 对一个小型 Count-Min Sketch 例子，把 hash 冲突看成随机变量，说明“预测信息”可能降低哪些不确定性，但不能跳过 worst-case 保证。

## 5. 与随机算法的桥

信息论常通过以下方式进入随机算法：

- 用熵描述随机选择或压缩后的状态空间；
- 用 KL/互信息比较真实分布、预测分布和采样分布；
- 用通信复杂度把分布式/流式问题转成信息下界；
- 用 conditional entropy 解释观察 sketch 或 verifier 反馈后还剩多少不确定性。
