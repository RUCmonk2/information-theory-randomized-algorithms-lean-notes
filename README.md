# 信息论、随机算法与 Lean 自学路线

建立日期：2026-08-14

这个文件夹服务于一条可以逐步落地的基础学习路线：先补足概率、信息论和随机算法，再学习 Lean 4 与 mathlib，最后把三者接到 AI4Math / AI4TCS 的可验证研究问题上。

这里的目标不是把三门课都学成完整课程，而是形成能够被科研调用的能力：

- 能读懂熵、KL 散度、互信息、编码和随机化算法的基本证明；
- 能分析随机算法的正确性、误差、空间/时间成本和失败概率；
- 能用 Lean 写出小型定理、检查证明并阅读 mathlib 代码；
- 能把候选算法、预测器或数学命题接入明确的 verifier；
- 每个阶段都有可运行、可检查、可复用的产出。

## 推荐顺序

1. [学习总览与进度](00_学习总览与进度.md)：先确定节奏、产出和停止条件。
2. [信息论](01_信息论/README.md)：从概率复习开始，依次学习熵/KL/互信息、编码/信道，再连接到 Sketch 和学习增强算法。
3. [随机算法](02_随机算法/README.md)：掌握概率工具、随机化算法和数据流 Sketch，再学习如何设计可审计 verifier。
4. [Lean 4 与 mathlib](03_Lean/README.md)：完成 Lean 4 基础语法、依赖类型、mathlib 检索和证明搜索。
5. [AI4Math / AI4TCS 交叉应用](04_AI4Math_AI4TCS交叉应用/README.md)：从三个小项目中选一个，留下证明、代码、反例或实验表。
6. [资源索引](05_资源索引.md)和[每周记录模板](05_每周记录/模板.md)：每次学习只记录一个最小真实交付，避免把“看过资料”当作完成。

## 12 周路线概览

| 阶段 | 周次 | 核心内容 | 阶段产出 |
| --- | --- | --- | --- |
| 基础 | 1 | 概率、条件概率、随机变量、期望与方差 | 一页概率工具表 + 10 道手算题 |
| 信息论 | 2-3 | 熵、条件熵、互信息、KL、链式法则和基本不等式 | 公式卡 + 小型熵/互信息计算 notebook |
| 编码与信道 | 4 | Huffman、无失真压缩、信道容量、随机编码直觉 | 一份编码实验和一页证明骨架 |
| 随机算法 | 5-6 | Monte Carlo/Las Vegas、Markov/Chernoff、随机抽样和哈希 | 3 个算法的保证/成本对照表 |
| 数据流与 Sketch | 7 | Count-Min、Count Sketch、sampling、mergeability | 经典 Sketch baseline + 误差曲线 |
| Lean 基础 | 8-9 | Lean 语法、命题即类型、归纳、重写、simp 和基础 tactic | 10-15 个可编译 theorem |
| 证明工程 | 10 | mathlib 检索、proof state、模块化和失败诊断 | 一张 Lean 证明调试卡 |
| 交叉项目 | 11-12 | 选择一个 AI4Math/AI4TCS 小项目 | 可复核仓库或正式研究笔记 |

如果每周只有 3 次 25 分钟，把每一周拆成“读一个概念、手算/编码一个例子、整理一张卡片”即可。

## 学习循环

每次学习按以下顺序进行：

```text
定义一个问题
  -> 读一个最小材料
  -> 手算或写 20-40 行代码
  -> 用定理、测试或 Lean kernel 检查
  -> 记录失败、边界和下一步
```

## 资料边界

- 这里的笔记是学习路线和自己的工作记录，不替代教材、论文或 mathlib 文档。
- 论文中的经验结果、形式证明和渐近保证分开记录，不把 benchmark 分数写成理论结论。
- Lean 接受证明只说明相对于当前形式化语句和导入库的内核正确；还要检查中文/自然语言命题是否被忠实形式化。
- 随机算法必须同时写清成功概率、误差参数、随机源、时间和空间成本。

## 第一周建议

先完成 `00_学习总览与进度.md` 的目标确认，然后阅读 `01_信息论/01_概率与信息量.md` 中的概率复习部分，手算二项分布和几何分布的期望、方差，再用 `02_随机算法/01_概率方法与随机化工具.md` 写一页 Markov/Chebyshev/Chernoff 对照。第一周不要安装 Lean 之外的大型环境，也不要开始训练模型。
