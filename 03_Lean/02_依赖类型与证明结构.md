# 依赖类型与证明结构

> 完整讲解见 [Lean 4 与 mathlib 自学讲义](讲义/Lean自学讲义.pdf)第 3--5 章；本文件保留为证明结构快速复习。

## 1. 需要形成的直觉

在 Curry-Howard 视角下：

- 命题是类型；
- 一个证明是该类型的项；
- 函数类型 `P -> Q` 是从证明 `P` 构造证明 `Q` 的程序；
- `P ∧ Q` 的证明是包含两个证明的结构；
- `P ∨ Q` 的证明带有左/右分支；
- `∀ x, P x` 是依赖函数，`∃ x, P x` 是依赖对。

## 2. 三种证明结构

### 直接构造

```lean
example (p q : Prop) : p -> q -> p ∧ q := by
  intro hp hq
  exact ⟨hp, hq⟩
```

### 归纳

面对 `Nat`、`List`、树或算法状态序列时，先找归纳不变量，再按 base/step 两部分证明。

### 重写与简化

`rw [h]` 做有方向的替换；`simp [defs]` 使用一组重写规则；二者都依赖表达式的精确类型，不能把“看起来相同”当作 definitional equality。

## 3. 与随机算法的对应

- 算法状态可定义为 `structure`；
- 合法状态是不变量 `Inv s : Prop`；
- 一次更新是 `step : State -> Input -> State`；
- 正确性是 `Inv s -> Inv (step s x)`；
- 最终性质是从 `Inv` 和终止条件推出的 theorem；
- 概率保证需要选择合适的概率库或先形式化有限样本空间，不能把 Python 实验当作 Lean 证明。

## 4. 练习

1. 定义带计数器的流摘要状态，并证明空摘要满足初始化不变量；
2. 定义一个列表上的 reservoir sampling 的简化状态机，只证明长度不超过 `k`；
3. 对一个二叉树定义节点数，证明左右子树分解公式；
4. 把 `Count-Min` 的“估计值不小于真实值”先写成一个不含概率的抽象 theorem，明确还缺哪些假设。

## 完成标准

看到一个自然语言定理时，能先拆成“对象定义、假设、状态、不变量、结论”，再决定使用直接证明、归纳还是结构化重写。
