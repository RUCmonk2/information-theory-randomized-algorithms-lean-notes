# 概念桥接表

> 完整讲解见 [AI4Math / AI4TCS 交叉应用讲义](讲义/AI4Math_AI4TCS交叉应用讲义.pdf)第 1--2 章及三个项目章；本文件保留为跨领域概念速查。

| 信息论 | 随机算法 | Lean / 形式化 | AI4Math / AI4TCS 问题 |
| --- | --- | --- | --- |
| 熵、条件熵 | 随机状态空间、采样信息 | 有限类型、状态表示 | 候选表示是否保留关键结构 |
| KL 散度 | 预测分布与真实分布偏差 | 可形式化的误差定义 | prediction error 如何进入 guarantee |
| 互信息 | 观测摘要后的不确定性 | 需要明确概率对象和假设 | verifier 反馈提供了多少有效信息 |
| union bound | 多个测试/失败事件 | 有限逻辑或概率 lemma | hidden tests 如何组合成整体保证 |
| 随机抽样 | Monte Carlo / sketch | 有限样本空间状态机 | 生成候选和估计器的可审计性 |
| 编码长度 | 通信/存储/搜索轨迹成本 | 数据结构与程序接口 | 证明证书或候选算法如何压缩传输 |
| 经典下界 | 不可能同时满足的资源目标 | 假设与结论显式化 | 区分经验收益和一般性理论改进 |

使用这张表时，每次只挑一行，写一个具体例子；不要把“概念有联系”直接写成“已有定理”。
